Detailed Introduction / 详细介绍

EN.
RealDeal is a full-stack social media platform designed with “industry-level” product requirements in mind: authenticated user workflows, rich post creation (including multi-image uploads), interactive engagement (likes, stars/bookmarks, comments, and nested replies), content categorization by genres, user progression via experience points and leveling, and a recommendation module to personalize content discovery.

The system is implemented with a clear separation between frontend and backend. On the backend, a Spring Boot service exposes REST APIs and follows a layered architecture (Controller → Service → Repository → Model/DTO), making business logic testable and maintainable. The frontend is built with React + TypeScript using route-based pages (dashboard/feed, create post, search results, and profile workflows), with a focus on reusable UI components and end-to-end test coverage.

中文.
RealDeal 是一个全栈社交平台项目，目标是贴近工业级产品需求：完整的用户登录/身份体系、多图发帖、 点赞/收藏/评论与嵌套回复、基于 Genre 的内容分类、经验值与等级成长系统，以及用于内容发现的个性化推荐模块。

项目采用前后端分离架构。后端基于 Spring Boot 提供 REST API，并采用 Controller → Service → Repository → Model/DTO 的分层组织方式，使业务逻辑可维护、可扩展、易测试。前端使用 React + TypeScript 进行页面路由组织， 通过可复用组件构建核心交互，同时配合端到端测试保证关键用户路径的可靠性。
