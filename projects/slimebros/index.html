Detailed Introduction / 详细介绍

EN. SlimeBros is a two-stage project centered on building a 2D game engine from scratch and validating it through a complete game application. The first stage focuses on engine development across the semester, starting from an empty repository and relying only on JavaFX as the core external library for rendering. All other subsystems are implemented in raw Java, with the goal of understanding how fundamental game engine architecture is constructed without relying on existing middleware or frameworks.

The engine is designed around several core subsystems commonly found in professional game engines, but implemented manually to expose their internal mechanics.

Rendering & Viewport. The engine provides a custom rendering pipeline built on top of JavaFX Canvas and SceneGraph primitives. A viewport and camera abstraction manages world-to-screen transformations, allowing the game world to render independently of window resolution and UI layout.

ECS-Inspired Architecture. GameObjects are lightweight containers composed of modular Components such as Transform, Sprite, and PhysicsBody. Behavior is implemented in Systems, which operate over relevant components each frame to handle movement, collision, rendering, and input processing. This separation enables flexible composition and a clearer logic flow.

Game Loop. A fixed-timestep game loop coordinates update, physics, and rendering phases, ensuring consistent behavior across machines and frame rates. This mirrors real-world engine patterns that balance simulation stability and rendering performance.

UI Screens & Workflow. The engine includes a screen/state manager supporting menus, gameplay screens, pause overlays, and transitions between states (e.g., title → gameplay → game over).

Resource Management. Resources such as textures, audio, and level data are handled through a centralized loading/caching mechanism to avoid duplication and improve runtime performance.

In the second stage, the engine is used to develop SlimeBros, a cooperative platformer located under the ptl/ directory. The game acts as a validation layer showing that the engine abstractions are sufficient to support real gameplay, physics interactions, camera behavior, and UI flow without architectural rewrites.

中文. SlimeBros 是一个围绕“从零搭建 2D 游戏引擎，并用完整游戏验证引擎可用性”的两阶段项目。第一阶段贯穿整个学期，从空仓库起步， 仅使用 JavaFX 作为渲染相关的核心外部库，其余全部用原生 Java 实现，目的是训练我们理解：不依赖现成中间件时， 一个游戏引擎的基础架构应如何被手工搭建出来。

引擎包含多项“专业引擎常见但在本项目中需要手写实现”的核心子系统：

渲染与视口（Rendering & Viewport）：基于 JavaFX 的 Canvas / SceneGraph 组合构建渲染流水线，并实现 viewport/camera 抽象来管理世界坐标到屏幕坐标的变换，使渲染不受窗口尺寸与 UI 布局影响。

类 ECS 架构（System / Component / GameObject）：GameObject 作为轻量容器，通过组合不同组件（如 Transform、Sprite、 PhysicsBody）形成实体；具体行为由 System 在每帧对相关组件集合进行处理，覆盖移动、碰撞、渲染与输入等逻辑，使结构更清晰、 更易扩展与调试。

主循环（Game Loop）：采用固定时间步（fixed timestep）将 update/physics/render 分相协调，保证不同机器与帧率下行为一致， 也更接近真实引擎的稳定模拟方式。

UI Screen 与状态流程：实现 screen/state 管理，支持菜单、游戏界面、暂停叠层以及状态切换（标题→游戏→结算等）。

资源管理（Resource Management）：通过统一的加载与缓存机制管理贴图、音频、关卡数据等资源，减少重复加载并提升运行性能。

第二阶段在该引擎之上开发协作平台游戏 SlimeBros（位于仓库 ptl/ 目录）。游戏作为验证层： 证明引擎抽象足以支撑真实玩法、物理交互、相机行为与 UI 流程，而不需要推翻或重写核心架构。
