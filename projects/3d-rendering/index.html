Real-Time 3D Rendering Engine
实时 3D 渲染引擎

A GPU-based real-time rendering project with shader lighting, shadow mapping, FXAA, model loading, scene hierarchy, and interactive camera controls — plus an understanding of CPU ray casting and BVH acceleration for realistic effects.

Detailed Introduction / 详细介绍

EN. This project implements a real-time 3D graphics rendering system in C++ using Qt Creator and the Qt3D/OpenGL pipeline for interactive visualization. The engine leverages GPU rasterization via GLSL shaders to compute per-vertex and per-fragment lighting in real time, fully utilizing the programmable graphics pipeline. The core rendering features include loading 3D models in .obj format, hierarchical scene transformations, and per-pixel Phong shading computed entirely on the GPU. In the shader implementation, vertex positions and normals are transformed by model/view/projection matrices, then passed to fragment shaders where ambient, diffuse, and specular lighting are computed using GLSL. Shadow mapping is implemented as a real-time shadowing technique. The scene is first rendered from the perspective of a directional light into a depth texture (the shadow map). In the main render pass, fragment positions are transformed into the light's clip space and compared against the shadow map to determine occlusion, enabling dynamic shadows in real time. To improve visual quality, Fast Approximate Anti-Aliasing (FXAA) is applied at the shader/post-process stage, smoothing jagged edges in the rasterized output without significant performance cost. Beyond the GPU pipeline, I have explored CPU-based ray casting and ray tracing techniques in prior work to gain deeper insight into realistic optical effects such as reflection and refraction. In those implementations, rays are recursively spawned according to material properties to simulate mirror-like surfaces and transparent media. To optimize performance, Bounding Volume Hierarchy (BVH) acceleration structures are used to prune intersection tests and maintain practical ray traversal performance. An interactive camera and viewport are integrated, allowing scene navigation via mouse and keyboard. Resource management routines encapsulate mesh, texture, and shader program loading to reduce duplication and improve runtime performance.

中文. 本项目实现了一个实时 3D 图形渲染系统，使用 C++ 与 Qt Creator，并基于 Qt3D/OpenGL 渲染管线实现交互式可视化。引擎利用 GPU Rasterization 和 GLSL 着色器进行实时光照计算， 完整利用可编程渲染管线的能力。 核心渲染功能包括从 .obj 模型文件加载几何体数据、层次场景变换，以及完全在 GPU 中 执行的 Phong 着色（包括环境光、漫反射和镜面反射分量）。在着色器中，顶点坐标和法线 通过模型/视图/投影矩阵变换后传递到片元着色器中进行光照计算。 阴影贴图技术被实现为实时阴影方法：先从光源视角将场景渲染到深度纹理中（shadow map）， 然后在主渲染阶段将片元位置转换到光源空间并与阴影贴图比较，从而判断是否可见，支持动态 阴影。 为了提升视觉质量，在 shader / 后处理阶段加入了快速近似抗锯齿（FXAA），在不显著损失 性能的前提下平滑了锯齿边缘。 除了 GPU 渲染管线外，我在早期实践中也研究过基于 CPU 的光线投射与光线追踪技术以深入 理解真实光学效果，如反射和折射。在这些实现中，根据材质属性递归生成射线以模拟镜面和 透明表面，通过包围体层次结构（BVH）优化求交测试以提高性能。 最后，引入了交互相机和视口控制，通过鼠标和键盘进行场景导航，同时封装了资源加载机制 以提高运行效率和复用性。
