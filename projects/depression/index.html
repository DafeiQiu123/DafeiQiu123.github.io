Detailed Introduction / 详细介绍

EN.
This project reproduces a recent research study on fine-grained depression symptom detection from Reddit posts. Instead of modeling depression as a single binary label, the task is formulated as a collection of symptom-level classification problems, where each symptom (e.g., anhedonia, anxiety, sleep problems) is evaluated independently against a control group.

The pipeline closely follows the original paper. We begin with large-scale dataset preprocessing, including text normalization, tokenization, and filtering using happiestfuntokenizing. Two complementary representation strategies are then applied: topic-based modeling via Latent Dirichlet Allocation (LDA), and contextualized text embeddings extracted from a pre-trained DistilRoBERTa model.

For LDA, each Reddit post is represented by its topic distribution, yielding interpretable low-dimensional embeddings that capture coarse semantic patterns associated with depressive language. For RoBERTa, contextual embeddings preserve fine-grained linguistic cues and semantic nuance.

Each symptom is evaluated using a binary classification setup (Symptom vs. Control) with 5-fold cross-validation to ensure robustness under class imbalance. Performance is measured using AUC, consistent with the original work.

中文.
本项目复现了一项关于 基于 Reddit 文本的细粒度抑郁症状检测 的研究。 与将抑郁作为单一标签不同，该方法将任务拆解为多个 症状级别的二分类问题，分别对快感缺失、焦虑、睡眠问题等症状进行建模。

实验流程严格遵循原论文设计。首先进行系统性 文本预处理（清洗、分词、规范化），并使用 happiestfuntokenizing 保证处理一致性。随后分别构建 LDA 主题嵌入 与 DistilRoBERTa 上下文嵌入， 用于刻画不同层次的语言特征。

每个症状均采用 5 折交叉验证 的“症状 vs 对照组”二分类设置， 使用 AUC 指标进行评估，从而确保结果的稳定性与可比性。
